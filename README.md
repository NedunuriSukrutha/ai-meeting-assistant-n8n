AI Meeting Assistant using n8n

Project Overview

The AI Meeting Assistant is an automation workflow built using n8n. It analyzes meeting transcripts and generates useful meeting information automatically.

Features

- Generates meeting summaries using AI.
- Extracts action items from meeting transcripts.
- Identifies responsible persons and deadlines when provided.
- Creates events in Google Calendar.
- Prepares professional follow-up emails using Gmail.

Technologies Used

- n8n — Workflow automation
- Google Gemini — AI-powered meeting analysis
- Google Calendar — Meeting event management
- Gmail — Follow-up emails

How It Works

1. The meeting transcript is provided as input.
2. The AI analyzes the transcript.
3. A meeting summary and action items are generated.
4. Google Calendar is used to create meeting events.
5. Gmail is used to prepare follow-up emails.

Project Purpose

The goal is to reduce manual work by automating meeting documentation, scheduling, and follow-up communication.

Note

This repository contains the exported n8n workflow in JSON format. Credentials and API keys must be configured securely in n8n before execution.
